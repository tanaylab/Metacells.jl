Gmara

Metacells.Gmara — Module

Access gene names lists from Gmara .

Note

All the functions here are thread-safe and can also be invoked from multiple parallel processes using the same CACHE_DIR . This directory can even be shared between multiple users as long as they have read-write permissions to the shared directory. This should even work on NFS mounted volumes shared between multiple servers.

Configuration

Metacells.Gmara.CACHE_DIR — Constant

The default ( $HOME/.cache/gmara ) location of the cache of downloaded Gmara data files.

You can override this by setting the METACELLS_GMARA_CACHE_DIR environment variable, or by passing an explicit cache_dir parameter to the functions.

The top-level under this is the version indicator, where main is always the latest and greatest version. Under each version we store the files in the same path as in github, with a .gz suffix for the compressed raw data, .jl_set.gz for serialized Julia set objects, .jl_dict.gz for serialized Julia dictionary objects, and .lock for temporary lock files for coordinating between parallel processes.

Metacells.Gmara.TIMEOUT — Constant

The default timeout in seconds (10) for waiting for a lock file in the Gmara cache. If not positive, will wait forever. If a process crashes very badly then a lock file may be left behind and may need to be removed by hand to allow access for the data.

You can override this by setting the METACELLS_GMARA_TIMEOUT environment variable, or by passing an explicit timeout parameter to the functions.

Functions

Metacells.Gmara.normalize_gene_name — Function 
normalize_gene_name(
    name::AbstractString;
    namespace::AbstractString,
    validate::Bool = false
)::AbstractString

Normalize a gene name in some namespace. Each namespace other than GeneSymbol has a pattern for its names (for example, ENSG00000124766 for EnsemblGene ). In such a namespace, this removes the .[0-9] version suffix (in the Ensembl and RefSeq namespaces), the _PAR_Y suffix (in the Ensembl namespaces, which GENCODE uses for the copy of a gene in the pseudoautosomal region of chromosome Y), and any trailing junk which contains no letters or digits (such as a trailing ; ). If the name does not match the pattern, then if validate this fails, otherwise this returns the name unchanged. To lookup a name in a list or a namespace, you need to normalize the query gene name accordingly. In other namespaces, the .[0-9] suffix is part of the name. For example, AC092171.3 and AC092171.5 are different genes. An unknown namespace is an error.

The case of a name is never changed, as Gmara names are in mixed case, differing between namespaces; for example, SOX4 for the human gene and Sox4 for the mouse one.

Metacells.Gmara.gmara_genes — Function 
gmara_genes(;
    species::AbstractString,
    [namespace::AbstractString = ```"GeneSymbol"```,
    list::Maybe{AbstractString} = ```nothing```,
    version::AbstractString = ```"main"```,
    cache_dir = CACHE_DIR,
    timeout::Real = TIMEOUT,
)::AbstractSet{<:AbstractString}

Return the set of names of a version of a list in a namespace of genes of some species . This returns all the names that are (probably) in the list; it a name isn't in the result, it is almost certain it does not belong in the list. As usual in Gmara, this includes everything that may be used as name, e.g. for Ensembl it includes genes, transcripts and proteins; for Symbol it includes approved and alises; etc. If the list is nothing , this just returns the set of known gene names in the namespace .

Metacells.Gmara.GmaraEnsemblGenes — Type 
struct GmaraEnsemblGenes
    ensembls_of_name::AbstractDict{<:AbstractString, <:AbstractSet{<:AbstractString}}
    final_ensembls_of_ensembl::AbstractDict{<:AbstractString, <:AbstractSet{<:AbstractString}}
end

The mappings of gene names to EnsemblGenes of some version of Gmara for some species, as returned by fetch_gmara_ensembl_genes . These are mappings rather than per-axis-entry vectors, so their names use of rather than per .

A final EnsemblGene is the end of a chain of replacements of retired identifiers. It is a current gene, or a retired identifier which has no replacement. It is the best identifier there is for the gene.

  • ensembls_of_name maps each name of some namespace to its final EnsemblGenes. A name which Gmara knows, but which has no EnsemblGene, maps to an empty set.
  • final_ensembls_of_ensembl maps each EnsemblGene identifier Gmara knows to its final EnsemblGenes. A final identifier maps to itself. A retired identifier which was replaced maps to the final EnsemblGenes it was replaced by (several, if it was split).
Metacells.Gmara.fetch_gmara_ensembl_genes — Function 
fetch_gmara_ensembl_genes(;
    species::AbstractString,
    [namespace::AbstractString = ```"GeneSymbol"```,
    version::AbstractString = ```"main"```,
    cache_dir = CACHE_DIR,
    timeout::Real = TIMEOUT],
)::GmaraEnsemblGenes

Fetch the mappings of gene names to EnsemblGenes of some version of Gmara for some species . This returns both the EnsemblGenes of each name of the namespace , and the final EnsemblGenes of each EnsemblGene identifier, so both always come from the same species and version. See GmaraEnsemblGenes .

Metacells.Gmara.collect_ensembl_genes — Function 
collect_ensembl_genes(;
    names::AbstractVector{<:AbstractString},
    gmara_ensembl_genes::GmaraEnsemblGenes,
)::AbstractVector{<:AbstractString}

Return the EnsemblGene of each of the names , using the ensembls_of_name of the gmara_ensembl_genes (see fetch_gmara_ensembl_genes ). This is the one EnsemblGene the name maps to, or empty if it maps to none or to several. The names are looked up as given, so in a namespace other than GeneSymbol they should be normalized first (see normalize_gene_name ).

This can be used to set vector_of_ensembl_per_gene when the data has no Ensembl identifiers.

Metacells.Gmara.EnsemblConsistency — Type 
struct EnsemblConsistency
    name::AbstractString
    ensembl::AbstractString
    normalized_ensembl::Maybe{AbstractString}
    name_ensembls::AbstractSet{<:AbstractString}
    final_ensembls::AbstractSet{<:AbstractString}
end

The consistency of the Ensembl identifier of a gene name with the mappings of Gmara, as returned by verify_consistent_ensembl_genes .

  • name and ensembl are as given.
  • normalized_ensembl is the ensembl without its suffixes (see normalize_gene_name ), or nothing if it is not in the form of an Ensembl identifier.
  • name_ensembls are the final EnsemblGenes Gmara maps the name to (see GmaraEnsemblGenes ).
  • final_ensembls are the final EnsemblGenes Gmara maps the normalized_ensembl to.

It also has computed Boolean properties. The first two are true when all is well:

  • is_consistent : none of the inconsistency properties listed below is true, so the ensembl identifies the gene of the name . The identifier may still have suffixes (such as a version).
  • ensembl_is_normalized : the ensembl is in the form of an Ensembl identifier, and has no suffixes.

The rest say what the inconsistency is. Several of them may be true at once (e.g. for a retired identifier which was replaced by a different gene):

  • name_is_empty : the name is empty.
  • name_is_unknown : the name is not empty, and Gmara maps it to no EnsemblGene.
  • ensembl_is_empty : the ensembl is empty.
  • ensembl_is_invalid : the ensembl is not empty, and is not in the form of an Ensembl identifier.
  • ensembl_is_unknown : Gmara does not know the normalized_ensembl .
  • ensembl_is_retired : Gmara maps the normalized_ensembl to other final EnsemblGenes.
  • ensembl_is_different : the name_ensembls and the final_ensembls are not empty, and have no EnsemblGene in common.
Metacells.Gmara.verify_consistent_ensembl_genes — Function 
verify_consistent_ensembl_genes(;
    names::AbstractVector{<:AbstractString},
    ensembl_per_name::AbstractVector{<:AbstractString},
    gmara_ensembl_genes::GmaraEnsemblGenes,
)::AbstractVector{EnsemblConsistency}

Verify that the Ensembl identifier of each of the names is consistent with the gmara_ensembl_genes (see fetch_gmara_ensembl_genes ). Returns the EnsemblConsistency of each name, in the same order. This only lists the inconsistencies; it is up to the caller to decide what to do about them.

The names are looked up as given, so in a namespace other than GeneSymbol they should be normalized first (see normalize_gene_name ).

This does not verify that the Ensembl identifiers are unique. To list the identifiers given to more than one name (and the indices of these names), use indices_of_duplicates from TanayLabUtilities , ignoring the empty identifiers: indices_of_duplicates(ensembl_per_name; empty_value = "") .

Metacells.Gmara.gmara_genes_mask — Function 
gmara_genes_mask(;
    names::AbstractVector{<:AbstractString},
    species::AbstractString,
    [namespace::AbstractString = ```"GeneSymbol"```,
    list::Maybe{AbstractString} = ```nothing```,
    version::AbstractString = ```"main"```,
    cache_dir = CACHE_DIR,
    timeout::Real = TIMEOUT],
)::AbstractVector{Bool}

Return a mask with, for each of the names in the namespace , whether it is in some version of a Gmara list for some species . If list is nothing , this marks the names that exist in the namespace. The names are normalized before they are matched (see normalize_gene_name ). For example, pass axis_vector(daf, "gene") as the names of the GeneSymbol namespace, or the vector_of_ensembl_per_gene as the names of the EnsemblGene namespace.

This is useful for comparing a mask with a Gmara list, without changing the data. To set the mask as a per-gene property, use set_gmara_genes_mask! .

Metacells.Gmara.set_gmara_genes_mask! — Function 
set_gmara_genes_mask!(
    daf::DafWriter;
    species::AbstractString,
    namespace::AbstractString,
    [list::Maybe{AbstractString} = ```nothing```,
    name_property::Maybe{AbstractString} = ```nothing```,
    mask_property::Maybe{AbstractString} = ```nothing```,
    cache_dir = CACHE_DIR,
    timeout::Real = TIMEOUT,
    overwrite::Bool = ```false```]
)::Integer

Set a gene property mask in daf based on some version of a Gmara list of some namespace for some species . We match the names of the genes in the namespace with the list names, and set the result as a per-gene mask_property (by default, $is_$ list ). If list is nothing , this just marks the gene names that exist in the namespace, and the mask_property must be specified. If overwrite , this will overwrite an existing property of the same name.

The names of the genes in the namespace are the per-gene name_property . By default, this is name (the gene axis entries) for the GeneSymbol namespace, and ensembl (see vector_of_ensembl_per_gene ) for the EnsemblGene namespace. It must be specified for any other namespace. The names are normalized before they are matched (see normalize_gene_name ).

Returns the number of genes that are set in the mask.

Metacells.Gmara.empty_gmara_cache! — Function 
empty_gmara_cache!()::Nothing

All requests are cached in-memory. This makes repeated requests cheap. This consumes some (modest amount of) memory; also, if the data in the server has been updated (which rarely happens), you will keep getting the old result. This function releases all the memory and forces all subsequent requests to query the server. In the common case the server tells us our disk cache data is up to date, we don't re-download it).
