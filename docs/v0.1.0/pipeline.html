Pipeline

Metacells.Pipeline — Module

Run whole stages of the metacells pipeline.

The functions here compute nothing themselves. Each runs a sequence of the computations of the rest of the package, in the order their inputs and outputs demand, which is otherwise something every caller would have to know and repeat.

Metacells

Metacells.Pipeline.prepare_metacells! — Function 
prepare_metacells!(
    daf::DafWriter;
    overwrite::Bool = ```false```,
)::Nothing

Aggregate the cells of each metacell, given which cells belong to which metacell. This computes everything about the metacells which follows from the cells alone - their UMIs, their sizes, and the fraction of the UMIs of each gene in each of them.

Types are optional. If the cells have a type, then so does each metacell, by the types of its cells; if they do not, then neither do the metacells, and everything else here is computed just the same.

Nothing here depends on the gene masks, so a repository this was run on can be shared by several analyses which use different masks. Do run it again whenever the assignment of cells to metacells changes, that is, after each round of sharpen_metacells! .

Inputs

Axes

cell (required): Sequenced single cells.

gene (required): Sequenced genes.

metacell (required): Minimal-sized groups of cells for robust point estimates.

Vectors

cell @ metacell ::AbstractString (required): The unique metacell each cell belongs to.

cell @ type ::AbstractString (optional): The type each cell belongs to.

gene @ is_excluded ::Bool (required): A mask of genes that are excluded from consideration.

Matrices

gene, cell @ UMIs ::Union{UInt16, UInt32, UInt64, UInt8} (required): The number of UMIs collected for each gene for each cell.

Outputs

Vectors

metacell @ type ::AbstractString (optional): The type each metacell belongs to.

metacell @ total_UMIs ::Union{UInt16, UInt32, UInt64, UInt8} (created): The total number of UMIs of all the non-excluded genes in each metacell.

metacell @ n_cells ::Union{UInt16, UInt32, UInt64, UInt8} (created): The number of cells in each metacell.

Matrices

gene, metacell @ UMIs ::Union{UInt16, UInt32, UInt64, UInt8} (created): The total number of UMIs of each gene in the cells of each metacell.

gene, metacell @ linear_fraction ::Union{Float32, Float64} (created): The linear fraction of the UMIs of each non-excluded gene in each metacell, out of the total UMIs.

gene, metacell @ log linear fraction ::Union{Float32, Float64} (created): The log base 2 of the linear fraction of the UMIs of each non-excluded gene in each metacell, out of the total UMIs.

Metacells.Pipeline.prepare_markers! — Function 
prepare_markers!(
    daf::DafWriter;
    overwrite::Bool = ```false```,
)::Nothing

Find the marker genes - the genes which distinguish between the metacells - rank them, and correlate each of them with every other.

Like prepare_metacells! , and for the same reason, nothing here depends on the gene masks. It does depend on the metacells, so run it again whenever they change.

Inputs

Axes

gene (required): Sequenced genes.

metacell (required): Minimal-sized groups of cells for robust point estimates.

Matrices

gene, metacell @ linear_fraction ::Union{Float32, Float64} (required): The linear fraction of the UMIs of each non-excluded gene in each metacell, out of the total UMIs.

gene, metacell @ log linear fraction ::Union{Float32, Float64} (required): The log base 2 of the linear fraction of the UMIs of each non-excluded gene in each metacell, out of the total UMIs.

Outputs

Vectors

gene @ is_marker ::Bool (created): A mask of genes that distinguish between cell states.

gene @ marker_rank ::Union{UInt16, UInt32, UInt64, UInt8} (created): The relative ranks of the marker genes.

Matrices

gene, gene @ correlation between markers ::Union{Float32, Float64} (created): The correlation between the log expression of pairs of marker genes across the metacells.

Metacells.Pipeline.prepare_skeletons! — Function 
prepare_skeletons!(
    daf::DafWriter;
    prev_daf::Maybe{DafReader} = nothing,
    rng::AbstractRNG = default_rng(),
    overwrite::Bool = ```false```,
)::Nothing

Choose the skeleton genes - the genes whose expression is taken to predict the rest - and compute what follows from them: which marker genes correlate with them, how far the metacells are from each other, and a 2D layout of the metacells based on that distance.

This is the part which the gene masks decide. Two analyses of the same metacells which differ only in their is_lateral , is_forbidden or is_regulator masks differ from here onwards, and only from here onwards, so the results of prepare_metacells! and prepare_markers! can be shared between them.

Give prev_daf to seed the layout from an earlier one, so that a metacell of the same cells is placed close to where it was, and successive rounds of sharpen_metacells! can be compared by eye.

Inputs

Axes

gene (required): Sequenced genes.

metacell (required): Minimal-sized groups of cells for robust point estimates.

cell (optional): Sequenced single cells.

Vectors

gene @ is_excluded ::Bool (required): A mask of genes that are excluded from consideration.

gene @ is_lateral ::Bool (required): A mask of genes that are lateral to the biological behaviors of interest.

gene @ is_forbidden ::Bool (required): A mask of genes that are forbidden from being used as skeleton genes.

gene @ is_regulator ::Bool (required): A mask of genes that regulate the expression level of other genes.

gene @ is_marker ::Bool (required): A mask of genes that distinguish between cell states.

metacell @ total_UMIs ::Union{UInt16, UInt32, UInt64, UInt8} (required): The total number of UMIs of all the non-excluded genes in each metacell.

cell @ metacell ::AbstractString (optional): The unique metacell each cell belongs to.

Matrices

gene, gene @ correlation between markers ::Union{Float32, Float64} (required): The correlation between the log expression of pairs of marker genes across the metacells.

gene, metacell @ linear_fraction ::Union{Float32, Float64} (required): The linear fraction of the UMIs of each non-excluded gene in each metacell, out of the total UMIs.

gene, metacell @ UMIs ::Union{UInt16, UInt32, UInt64, UInt8} (required): The total number of UMIs of each gene in the cells of each metacell.

Outputs

Vectors

gene @ is_skeleton ::Bool (created): A mask of genes that are used to predict the values of the rest of the genes.

gene @ is correlated with_skeleton ::Bool (created): A mask of (marker) genes that have significant correlation with any of the skeleton genes.

metacell @ umap_x ::Union{Float32, Float64} (created): The X coordinate of each metacell in a 2D UMAP projection.

metacell @ umap_y ::Union{Float32, Float64} (created): The Y coordinate of each metacell in a 2D UMAP projection.

Matrices

metacell, metacell @ max skeleton fold_distance ::Union{Float32, Float64} (created): The maximal significant fold factor between the fraction of skeleton genes between the metacells.

metacell, metacell @ euclidean skeleton fold_distance ::Union{Float32, Float64} (created): The Euclidean distance between the log of the fraction of the skeleton genes between the metacells.
