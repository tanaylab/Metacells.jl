Focus

Metacells.Focus — Module

Reduce a large set of metacells to a smaller, non-redundant focus set, for analyzing large data sets.

Metacells

Metacells.Focus.compute_focus_metacells! — Function 
compute_focus_metacells!(;
    full_daf::DafReader,
    focus_daf::DafWriter,
    max_redundant_fold::Real = ```0.5```,
    n_neighbors::Integer = ```15```,
    gene_fraction_regularization::AbstractFloat = ```0.0001```,
    max_fold_gene_fraction_regularization::AbstractFloat = ```1.0e-5```,
    max_fold_min_significant_gene_UMIs::Integer = ```40```,
    max_fold_confidence::AbstractFloat = ```0.9```,
    max_fold_min_confidence_UMIs::Real = ```3```,
    min_marker_gene_max_fraction::AbstractFloat = ```0.0001```,
    min_marker_gene_range_fold::Real = ```2```,
    min_marker_quantile::Real = ```0```,
    overwrite::Bool = ```false```,
)::Nothing

Choose the focus metacells of the full_daf . Create the focus metacell_axis of the focus_daf with the focus metacells, and its cell_axis with their cells. Create its gene_axis with all the genes, unless it already has one, e.g. from a base repository of gene masks. Set its vector_of_is_skeleton_per_gene to the skeleton genes that are still markers of the focus metacells.

This works in passes, until a pass drops no metacell. Each pass:

  • Keeps only the skeleton genes that are still markers of the remaining metacells, using the min_marker_gene_max_fraction , min_marker_gene_range_fold and min_marker_quantile (see compute_vector_of_is_marker_per_gene! ).
  • Finds the n_neighbors nearest neighbors of each remaining metacell, using the Euclidean distance between the log of the fractions of the skeleton genes, adding the gene_fraction_regularization (see compute_matrix_of_knn_euclidean_skeleton_fold_distance_per_metacell_per_metacell! ).
  • Computes the maximal confident fold of the skeleton genes between each metacell and each of its neighbors, using the max_fold_gene_fraction_regularization , max_fold_min_significant_gene_UMIs , max_fold_confidence and max_fold_min_confidence_UMIs (see compute_metacells_blocks! ).
  • Considers the pairs whose maximal fold is at most max_redundant_fold , in ascending order of the fold. If both metacells of a pair are still there, drops the one with fewer cells. On a tie, it drops the one with fewer UMIs, and on a tie, the one with the higher index.

This only creates the axes and the skeleton genes mask of the focus_daf . To populate the rest of the data, use copy_focus_metacells_data! .

Metacells.Focus.copy_focus_metacells_data! — Function 
copy_focus_metacells_data!(;
    full_daf::DafReader,
    focus_daf::DafWriter,
    excluded_contract::Contract,
)::Nothing

Copy the data of the full_daf into the focus_daf , restricted to the focus metacells and cells that compute_focus_metacells! chose. Data the focus_daf already has is kept. This includes the focus skeleton genes mask, and the gene masks if the focus_daf rests on their repository.

The outputs of the excluded_contract are not copied. These are typically the outputs of the computations that are redone for the focus metacells, because they depend on which metacells there are (e.g., the marker genes). Both layouts of an excluded matrix are excluded.
